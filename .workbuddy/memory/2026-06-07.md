# 2026-06-07 工作日志

## 项目全面阅读 - ConcertAI

完整阅读了 ConcertAI 项目，以下为关键信息摘要：

### 项目定位
演唱会管家 AI 平台，AI 角色名为"小团团"，与美团合作。

### 技术栈
- 后端：Spring Boot 3.4.0 + Java 17 + Spring AI 1.0.0-M6 + DeepSeek-Chat + MyBatis Plus 3.5.12 + MySQL + Redis + WebSocket(STOMP)
- 前端：React 18 + Vite 5 + Tailwind CSS + Three.js（3D 背景）+ Framer Motion + react-markdown
- 运行端口：后端 8081（开发）/ 8082（生产），前端 5175，后端 API Base: `/concert/api`

### 数据库（concert_db）
- `concert`：演唱会表（歌手、城市、场馆、时间、票价、座位图标记等）
- `user_follow_concert`：用户关注演唱会
- `user_reminder`：用户提醒（TICKET/PRICE/TRAVEL/WEATHER/COUNTDOWN/FOLLOW）
- `hotel`：酒店（城市ID关联）
- `scenic`：景点
- `city_info`：城市信息
- `playlist`：歌手歌单（JSON）

### Agent 架构（核心）
三种 Agent 路由：
1. **ConcertOrchestratorAgent**：从演唱会详情页，带 concertId → ReAct 循环（最多 6 轮）
2. **DedicatedConcertAgent**：演唱会详情页，无 concertId → 直接 ChatClient 调用
3. **GeneralAssistantAgent**：AI 助手页面（hasIdentity=false）→ 通过 ReActOrchestrator

**ReActOrchestrator**：实现真正的 ReAct 循环（思考→工具调用→观察），推理链路保存到 Redis（TTL 10min）。

### 工具集（Tool）
- **ConcertTools**：getAllSingers、getSingerConcerts、getConcertDetail、getAllConcerts
- **PlanningTools**：searchMeituanFood/Hotel/Tickets、estimateMeituanRide、createMeituanReminder、getWeather、searchTrains、getSeatInfo（读 seatmap_configs/{id}.json）
- **MusicTools**：getSingerPlaylist、searchSongsByMood、extractSingerFromInput（均为 Mock 数据）

### 提醒系统
- **DynamicReminderService**：Redis List 存储实时提醒（key: `reminder:user:{userId}`）
- **ActiveReminderScheduler**：每天10点 cron，查7天内演唱会 → 推送给关注用户
- **SmartReminderScheduler**：每5分钟检查，生成 COUNTDOWN/TRAVEL/WEATHER/TICKET 提醒；每分钟发送待发提醒

### 会话存储
- **RedisChatMemoryStoreImpl**：key=`chat:session:{sessionId}`，JSON 存储 Message 列表
- **ConcertContextHolder**：key=`orch:session:{sessionId}`，UserSession 对象，TTL 72小时
- **ReActTraceStore**：key=`react_trace:{sessionId}`，推理步骤 List，TTL 10分钟

### 前端路由
- `/` 或 `/home`：Home 首页（3D 背景 + 演唱会列表）
- `/concerts`：演唱会列表
- `/concerts/:id`：演唱会详情（含座位图、AI 对话入口）
- `/agent`：通用 AI 助手页面
- `/profile`：个人中心（关注列表、提醒管理）
- `/reminders`：提醒页面
- `/music`：音乐播放器页面

### 前端关键组件
- **AgentChatWindow**：AI 对话窗口（支持 SSE 流式输出）
- **AgentThinkingPanel**：ReAct 推理链路可视化面板
- **SeatMapStage / SeatMapViewer**：2.5D 座位图展示（Three.js）
- **TripPlanForm**：行程规划表单
- **ReminderPolling**：轮询未读提醒
- **GlobalPlayer**：全局音乐播放控制栏
- **FuturisticScene**：全局 3D 科幻背景

### 座位图配置
`src/main/resources/seatmap_configs/{concertId}.json`，包含 backgroundImage + areas（热区）
